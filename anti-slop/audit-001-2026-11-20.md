## Numbered Findings List

### Finding 1 [HIGH - R-02 Hard Gate]
- Rule: R-02 (Copywriting - Em Dash Prohibition)
- Location: src/app/admin/audit-logs/page.tsx:61, src/app/admin/chapters/page.tsx:237, src/app/admin/chapters/page.tsx:241, src/app/admin/imports/[id]/page.tsx:104
- Reason: Literal em dash character ("—") used as fallback text in table columns, violating the absolute ban on em dashes.
- Proposed Remediation: Replace literal em dash with standard hyphen ("-") or explicit fallback string ("None").

### Finding 2 [HIGH - R-26 / R-39 Hard Gate]
- Rule: R-26 (Interactive Elements) and R-39 (Accessible Semantics & Interaction Affordances)
- Location: src/app/admin/manga/page.tsx:44,52,55; src/app/admin/chapters/page.tsx:103,106,148,153; src/app/admin/media/page.tsx:42,45; src/app/admin/genres/page.tsx:42; src/app/admin/manga/[id]/page.tsx:107; src/app/admin/reports/page.tsx:36
- Reason: Browser native window.alert() and window.confirm() used for actions and errors, blocking the UI thread and breaking accessible keyboard/modal dialog standards.
- Proposed Remediation: Replace native alert and confirm with accessible in-app modal confirmation dialogs and toast/inline alert feedback.

### Finding 3 [HIGH - R-32 / R-39 Hard Gate]
- Rule: R-32 (Keyboard Accessibility) and R-39 (Accessible Semantics)
- Location: src/app/admin/media/page.tsx:70-75
- Reason: Hidden file input with pointer-events-none button inside label creates an inaccessible control unreachable by keyboard Tab and lacking visible focus indicators.
- Proposed Remediation: Implement an accessible file trigger button with proper keyboard focus ring and programmatic file dialog invocation.

### Finding 4 [HIGH - R-24 / C-3 Hard Gate]
- Rule: R-24 (Navigation) and Craftsmanship C-3 (Content-Driven Composition)
- Location: src/components/navigation/AdminSidebar.tsx:28-29; src/app/admin/page.tsx:55-61,79-84,119-161
- Reason: Obsolete external scraper and API provider navigation ("API Providers", "Import Engine", "Universal external REST connectors") remain prominent after transition to a self-hosted CMS.
- Proposed Remediation: Remove external scraper links from AdminSidebar; replace dashboard provider panels with self-hosted CMS operational metrics (Storage, Chapter Uploads, Content Review).

### Finding 5 [HIGH - R-39 Hard Gate]
- Rule: R-39 (Accessible Semantics & Interaction Affordances)
- Location: src/app/admin/manga/page.tsx:127,201-204; src/app/admin/chapters/page.tsx:283-290
- Reason: Manga cover previews lack descriptive alt attributes and icon-only delete action buttons lack aria-label attributes.
- Proposed Remediation: Add descriptive alt attributes (e.g. alt={m.title + " cover"}) and aria-label="Delete manga" / aria-label="Delete chapter".

### Finding 6 [HIGH - R-26 / R-27 Hard Gate]
- Rule: R-26 (Interactive Elements) and R-27 (UI States)
- Location: src/app/admin/manga/page.tsx:29,48; src/app/admin/chapters/page.tsx:44,60,80,150
- Reason: Admin views query unversioned legacy endpoints (/api/manga, /api/chapters) instead of canonical versioned admin REST contracts (/api/v1/admin/manga, /api/v1/admin/chapters).
- Proposed Remediation: Standardize all admin data fetching and mutations on versioned /api/v1/admin/ endpoints with complete error and loading state boundaries.

### Finding 7 [HIGH - R-25 Hard Gate]
- Rule: R-25 (Color Contrast)
- Location: src/app/admin/audit-logs/page.tsx:63, src/app/admin/manga/page.tsx:150, src/app/admin/media/page.tsx:100, src/app/admin/genres/page.tsx:96
- Reason: Tiny text (10px) with text-muted-foreground or text-cyan-400/60 against dark glass fails the WCAG AA 4.5:1 contrast requirement.
- Proposed Remediation: Elevate secondary text sizes to a minimum of 11px/12px and adjust foreground luminance to maintain minimum 4.5:1 contrast ratio.

### Finding 8 [MEDIUM - R-04 Purpose-Gate]
- Rule: R-04 (Icons)
- Location: src/app/admin/layout.tsx:41; src/app/admin/page.tsx:18,70; src/app/admin/settings/content-policy/page.tsx:385,434,507,872; src/components/navigation/AdminSidebar.tsx:21
- Reason: Generic AI sparkle (Sparkles) and lightning (Zap) glyphs used as decorative elements without functional or semantic relevance.
- Proposed Remediation: Remove decorative Sparkles and Zap icons; replace with domain-specific icons (e.g. ShieldCheck, Sliders, Activity) or clean text.

### Finding 9 [MEDIUM - R-01 / R-10 Purpose-Gate]
- Rule: R-01 (Color & Gradients) and R-10 (Glassmorphism)
- Location: src/components/navigation/AdminSidebar.tsx:109; src/app/admin/page.tsx:99,120,164; src/app/admin/layout.tsx:25
- Reason: Active sidebar links use generic blue-to-cyan gradient and every dashboard card applies liquid-glass backdrop blurs simultaneously, exceeding the glassmorphism dose cap.
- Proposed Remediation: Replace active link gradient with a solid deliberate accent; reduce backdrop blur to 1-2 focused containers to establish clear visual depth.

### Finding 10 [MEDIUM - R-09 Purpose-Gate]
- Rule: R-09 (Badges)
- Location: src/app/admin/layout.tsx:49-57; src/components/navigation/AdminSidebar.tsx:121
- Reason: Decorative capsule badges stacking pill shapes, glows, and monospaced text ("SSRF Guard Active", "PostgreSQL Ready", "HITL") without interactive status triggers.
- Proposed Remediation: Simplify header indicators to functional clean status indicators or remove non-actionable status capsules.

### Finding 11 [MEDIUM - R-14 Purpose-Gate]
- Rule: R-14 (Feature Cards)
- Location: src/app/admin/genres/page.tsx:84-98
- Reason: Copy-paste identical card grid with no visual hierarchy, action buttons, or edit/delete controls.
- Proposed Remediation: Convert genre list into a structured table with edit/delete actions, or add clear administrative management controls to cards.

### Finding 12 [LOW - R-31 Quality Locks]
- Rule: R-31 (Every Decision Must Have a Reason)
- Location: Entire src/app/admin/ module
- Reason: Admin UI lacks an explicit design direction document specifying deliberate typography, color tokens, and layout density for CMS data management.
- Proposed Remediation: Document the administrative design decisions (purpose of elevation, density, color mapping) in DESIGN.md.
